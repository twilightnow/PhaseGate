# PhaseGate Backlog

- Type: task
- Status: active
- Reader: both
- Use when: 需要查看尚未沉淀为正式文档或代码的待处理事项时
- Source of truth: 是
- Update when: 待办被实现、被放弃或需要转入正式文档时

## Purpose

集中保留仍有讨论价值但不应混入长期文档的事项。

## Scope

包含：待讨论问题、文档治理后续项、产品待扩展点。

不包含：已经稳定的规则、已落地功能说明。

## Documentation

- `progress.md` 的 Phase Summary 追加策略仍需评估维护性。
- 后续继续观察文档最小化策略是否足够，尤其是任务书和设计书边界。
- 如主文档稳定，可继续删除 `archive/legacy-2026-04/` 中没有追溯价值的旧稿。

## Product / Workflow

- 多模型配置与不同阶段的 runner 调度策略。
- 多任务并行时 `progress.json` 和任务组织方式。
- 跨阶段断点再续策略。
- 多语言 prompt 是否继续保留完整多套版本。
