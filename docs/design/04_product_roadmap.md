# PhaseGate 设计书 — 产品形态分阶段规划

> 版本 0.1 | 2026年4月

---

## 第一阶段：纯文档（MVP）

**目标：** 验证流程本身是否有效，收集反馈。

**内容：**
- 流程规范文档（本设计书系列）
- 各类模板文件（需求、设计书、接口契约、进度文档）
- 一个完整的真实项目示例

**交付物：** GitHub 仓库 + README

---

## 第二阶段：CLI 工具

在文档基础上加执行层，自动化以下操作：

- 读取进度文档，判断下一步
- 调用 AI CLI 执行对应阶段
- 更新进度文档
- 检查架构约束
- 通知人工介入点

**命令接口：**

```bash
# 初始化项目
phasegate init

# 开始需求讨论
phasegate chat

# 查看当前状态
phasegate status

# 执行下一步（自动判断）
phasegate run

# 对指定模块发起 review
phasegate review [module-name]

# 查看进度
phasegate progress
```

**技术选型：** Node.js（与前端生态一致，开发者熟悉）

---

## 第三阶段：VSCode 扩展

在 CLI 基础上套可视化壳。

**侧边栏功能：**

- 需求讨论对话界面（多轮，有记录）
- 阶段流转可视化（当前在哪个阶段，每个阶段状态）
- 模块进度面板（哪些完成、哪些在跑、哪些阻塞）
- review 结果展示
- 一键触发下一步

**架构原则：** 扩展只做 UI，逻辑调用 CLI，两层解耦。
